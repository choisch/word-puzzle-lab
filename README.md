# 낱말퍼즐 메이커

브라우저에서 바로 실행되는 단일 페이지 Word Search 퍼즐 생성기입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 별도 서버나 설치가 필요 없습니다.

## 현재 기능
- 대상 연령: 5–7세 / 8–10세 / 11–13세 / 14–17세 / 성인
- 관심사: 동물, 음식, 자연, 우주, 스포츠, 과학·기술, 믹스
- 난이도: 쉬움 / 보통 / 어려움
- 퍼즐 크기: 8×8 ~ 20×20
- 낱말 수: 5 ~ 18개
- 대각선 / 역방향 배치 옵션
- 사용자 지정 낱말 추가
- 정답 표시
- 인쇄
