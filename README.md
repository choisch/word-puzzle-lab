# 낱말퍼즐 메이커

브라우저에서 바로 실행되는 퍼즐 생성기입니다. 현재 **가로세로 낱말퀴즈**와 **숨은 낱말 찾기** 두 가지 모드를 지원합니다.

## 실행
GitHub Pages: https://choisch.github.io/word-puzzle-lab/

별도 서버나 설치가 필요 없습니다.

## 현재 기능
- 퍼즐 모드
  - 가로세로 낱말퀴즈(Crossword)
  - 숨은 낱말 찾기(Word Search)
- 대상 연령: 5–7세 / 8–10세 / 11–13세 / 14–17세 / 성인
- 관심사: 동물, 음식, 자연, 우주, 스포츠, 과학·기술, 믹스
- 난이도: 쉬움 / 보통 / 어려움
- 퍼즐 크기 및 낱말 수 조절
- 가로세로 퍼즐 자동 교차 배치
- 힌트를 보고 직접 답 입력
- 채점 및 정답 보기
- 사용자 지정 `정답 = 힌트` 추가
- 숨은 낱말의 대각선 / 역방향 배치
- 인쇄

## 구현 방식
현재 버전은 AI API를 사용하지 않습니다.

- 문제은행: 브라우저에 내장된 `정답 + 힌트` 데이터
- 가로세로 퍼즐: 공통 글자를 기준으로 자동 교차 배치하는 로컬 알고리즘
- 숨은 낱말: 로컬 배치 알고리즘

향후 AI를 붙일 경우에는 연령, 관심사, 학습 수준에 맞는 새로운 `정답 + 힌트` 세트를 만드는 용도로만 선택적으로 사용할 수 있습니다. 퍼즐 배치 자체는 계속 로컬 알고리즘으로 처리할 수 있습니다.

## 테트리스

게임 홈의 테트리스 카드 또는 https://choisch.github.io/word-puzzle-lab/tetris.html 에서 실행합니다.

- 모바일: 화면 버튼으로 이동·회전·즉시 낙하, 이동 버튼 길게 누르기 지원
- PC 키보드: ←/→ 이동, ↑/X 시계 방향 회전, Z 반시계 방향 회전
- ↓ 빠르게 내리기, Space 즉시 낙하, P/Esc 일시정지, Enter 시작/재시작
- 10×20 게임판, 7종 블록, 다음 블록과 착지 위치 표시
- 10줄마다 레벨 및 속도 증가, 최고 점수는 브라우저에 저장
- 창 전환 시 자동 일시정지

게임 규칙 확인: `node tests/tetris.test.cjs`

## 크루 매치

`crew-match.html`: 어몽어스풍 크루를 가로·세로·양쪽 대각선으로 3명 이상 맞추는 퍼즐입니다. 이웃한 두 크루를 클릭/터치하거나 스와이프해 교환합니다(대각선 이웃 포함). 성공한 교환 30회, 낙하 및 연쇄 배수, 힌트, 최고 기록 저장, 선택형 효과음을 지원합니다.

게임 규칙 확인: `node tests/crew-match.test.cjs`

## 크루 드롭

`crew-drop.html`: 6×12 보드에 3명짜리 세로 바를 쌓는 낙하 퍼즐입니다. 좌우 이동, 바 내부 순서 순환, 즉시 낙하를 지원합니다. 같은 색 3명 이상이 가로·세로·양쪽 대각선으로 이어지면 전기 효과와 함께 사라지고, 중력에 의한 연쇄가 이어집니다. 30명 제거마다 속도가 증가합니다. 두 크루 게임 모두 색을 구분하기 쉬운 둥근 색상 박스를 사용합니다.

게임 규칙 확인: `node tests/crew-drop.test.cjs`
